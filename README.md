# IT Systems Home Lab — Help Desk to Systems Administration

Hands-on IT infrastructure labs built across Windows Server, Active Directory, Microsoft Entra ID, and IT service management platforms — using PowerShell, Microsoft Graph API, and ServiceNow. Built to develop real troubleshooting and administration experience on the path from help desk support toward Systems Administration.
